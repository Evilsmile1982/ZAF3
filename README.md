# Z.AERO Fehlersuche

Lokale Android-App für die Fehlerbehebung.

## Funktionen
- Benutzer- und Profi-Modus
- Profi-Anmeldung mit dem aktuell gewünschten Master-Passwort `Chefe`
- Bereiche Anfahren und Abstellen
- Fehlersuche ab 3 Zeichen
- Fehler, Ursache und Lösung anlegen/bearbeiten/löschen
- Bilder pro Fehler lokal auf dem Gerät speichern
- Keine Cloud-Datenbank erforderlich

## Build
Das Projekt verwendet Android Gradle Plugin 9.4.0 und Gradle 9.6.0. AGP 9.4 unterstützt API 37 und benötigt mindestens Gradle 9.6 und JDK 17.
